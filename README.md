## ทำไมต้อง Waku

- **หลายเว็บในแอปเดียว** — ค้นหา ดูรายการล่าสุด และเล่นจาก Anime-Waku, Anime-Sugoi, Anifume, AnimeRuka และ FairyAnime
- **ไม่สะดุด** — เว็บไหนล่มหรือเซิร์ฟเวอร์เสีย แอปหาตอนเดียวกันจากเว็บอื่นแล้วเล่นต่อให้เอง
- **ชัดที่สุดเสมอ** — ดึงวิดีโอจากตัวเล่นหลักของแต่ละเว็บที่ความละเอียดสูงสุด (สูงสุด 1080p) เลือกความละเอียดเองได้ถ้าเว็บมีให้
- **ไม่มีโฆษณา ไม่มีป๊อปอัป** — เล่นในตัวเล่นของแอปเอง ([rmp](https://github.com/sapph1rer/rmp) + libmpv)

## ฟีเจอร์

**ดูอนิเมะ**
- หน้า Home แบบสตรีมมิ่ง: ภาพแนะนำใหญ่, แถว "ดูต่อ", เรื่องใหม่ของแต่ละเว็บ
- หน้าเรื่อง: ปก ภาพพื้นหลัง เรื่องย่อ คะแนน **ชื่อตอนและเรื่องย่อของแต่ละตอน** (จาก AniList / ani.zip / Kitsu)
- แยก **ซับไทย / พากย์ไทย** จำว่าดูแบบไหนล่าสุด
- **ข้ามเพลงเปิด / เพลงปิด** อัตโนมัติ (ข้อมูลจาก AniSkip) หรือกดปุ่ม "ข้ามเพลงเปิด" เอง
- **ตอนถัดไปเร็ว** — แอปเตรียมลิงก์ตอนถัดไปไว้ตั้งแต่ใกล้จบตอน
- ดูต่อจากจุดที่หยุดไว้ แถบความคืบหน้าทุกตอน

**ค้นหา**
- ค้นหาทุกเว็บพร้อมกัน พิมพ์ชื่อไทย / อังกฤษ / โรมาจิ ผิดนิดหน่อยก็เจอ
- **ค้นหาด้วยภาพ** — วางภาพหน้าจอ (Ctrl+V / ลากมาวาง) แอปบอกว่าเรื่องอะไร ตอนไหน นาทีไหน แล้วกดเล่นจากฉากนั้นได้เลย (trace.moe)
- **ค้นหาแบบละเอียด** (Browse) — กรองตามแนว รูปแบบ (TV / มูฟวี่ / OVA) ปี ฤดู สถานะ คะแนน เรียงตามยอดนิยม / มาแรง / คะแนน
- **ลำดับการดู** — ทุกภาค ซีซั่น มูฟวี่ OVA ของเรื่องนั้นเรียงตามวันฉาย บอกว่าดูไปถึงไหนแล้ว
- **ตารางฉาย (On Air)** — รายสัปดาห์ตามเวลาเครื่อง

**ดาวน์โหลด**
- ดาวน์โหลดทีละตอนหรือทั้งซีซั่น เก็บไว้ในโฟลเดอร์ `Downloads` ข้างโปรแกรม
- แท็บดาวน์โหลดแสดงเป็นเรื่องๆ เหมือนหน้า Home ดูได้แม้ไม่มีเน็ต

**ดูกับเพื่อน**
- **Watch Party** — สร้างห้องแล้วส่ง **รหัสห้อง** (เช่น `K7F3-9QMX`) ให้เพื่อน ดูพร้อมกันจากที่ไหนก็ได้
  เล่น / หยุด / เลื่อน / เปลี่ยนตอน ตามกันทุกคน มีแชทบนวิดีโอ — **ข้อความเข้ารหัส AES-256 ด้วยรหัสห้อง**
- **Discord Rich Presence** — โชว์ใน Discord ว่ากำลังดูเรื่องอะไร ตอนไหน

**อื่นๆ**
- หน้า **สถานะแหล่ง** — เว็บไหนเร็ว / ช้า / ล่ม และล้มเหลวเพราะอะไร
- **อัปเดตเอง** จาก GitHub ทั้งตัวแอปและกฎการดึงข้อมูลของแต่ละเว็บ (เว็บเปลี่ยนหน้าตา → แก้ได้โดยไม่ต้องลงแอปใหม่)
- ภาษาไทย / อังกฤษ, คลิกขวาเพื่อแก้เรื่องที่จับคู่ข้อมูลผิด (Identify)

## ติดตั้ง

1. ไปที่หน้า [**Releases**](https://github.com/sapph1rer/waku-app/releases/latest) ดาวน์โหลด `waku-windows-x64.zip`
2. แตกไฟล์ไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ (เช่น `D:\Apps\Waku`) — **อย่าไว้ใน Program Files** เพราะแอปต้องอัปเดตตัวเองและเก็บไฟล์ดาวน์โหลดข้างโปรแกรม
3. เปิด `waku-app.exe`

ต้องการ: Windows 10 / 11 (64-bit) และ [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (มีอยู่แล้วใน Windows 11 และ Windows 10 ที่อัปเดตล่าสุด)

> Windows SmartScreen อาจเตือนเพราะโปรแกรมไม่มีลายเซ็นดิจิทัล — กด "More info" › "Run anyway"

### ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `waku-app.exe` | ตัวแอป |
| `waku-browser.exe` | ตัวช่วยผ่าน Cloudflare และอ่านหน้า player ของบางเว็บ (ใช้ WebView2) |
| `libmpv-2.dll` | ตัวถอดรหัสวิดีโอของตัวเล่นในตัว (ถ้าไม่มี แอปมีปุ่มดาวน์โหลดให้ในหน้าตั้งค่า) |
| `Downloads\` | ตอนที่ดาวน์โหลดไว้ (สร้างเองเมื่อดาวน์โหลดครั้งแรก) |
| `mpv\yt-dlp.exe` | ไม่บังคับ — สำหรับเซิร์ฟเวอร์อย่าง ok.ru |
| `fonts\*.ttf` | ไม่บังคับ — ฟอนต์ไทยที่ชอบ (ไม่มีจะใช้ Leelawadee UI ของ Windows) |

ข้อมูลของแอป (ประวัติการดู รายการของฉัน การตั้งค่า) อยู่ที่ `%APPDATA%\waku\` แคชอยู่ที่ `%LOCALAPPDATA%\waku\`

## ใช้งาน

| อยากทำ | ทำยังไง |
|---|---|
| ดูเรื่องที่ค้างไว้ | Home › แถว "ดูต่อ" (กด ✕ ที่การ์ดเพื่อเอาออก) |

| ดาวน์โหลด | หน้าเรื่อง › ไอคอนดาวน์โหลดท้ายแต่ละตอน หรือ "ดาวน์โหลดทั้งหมด" |

### Watch Party (ดูด้วยกัน)

1. แถบซ้าย › **Party** › ตั้งชื่อของคุณ
2. **ผ่านอินเทอร์เน็ต:** กด "สร้างห้อง" แล้วส่งรหัสห้องให้เพื่อน → เพื่อนใส่รหัส แล้วกด "เข้าร่วม"
3. เปิดเรื่องแล้วเล่นตามปกติ ทุกคนในห้องจะเปิดตอนเดียวกันและเล่นตามกัน

- แต่ละเครื่องโหลดวิดีโอเอง แอปส่งแค่คำสั่ง (เล่น / หยุด / ตำแหน่ง / ตอน / แชท)
- ข้อความผ่าน [ntfy.sh](https://ntfy.sh) โดย **เข้ารหัสด้วยรหัสห้อง** — คนที่ไม่มีรหัส (รวมถึง ntfy.sh) อ่านไม่ได้ ให้รหัสเฉพาะคนที่ชวน
- ntfy.sh จำกัดประมาณ 250 ข้อความ/วัน/เน็ต แอปจึงส่งเฉพาะตอนมีคนกดอะไร ปกติดูกันหลายชั่วโมงก็ไม่เต็ม
- **อยู่ Wi-Fi / LAN เดียวกัน** (หรือ VPN อย่าง Tailscale): เลือกแท็บ "วงเดียวกัน (IP)" — เร็วกว่าและไม่มีจำกัด
- ไฟล์ที่ดาวน์โหลดไว้จะไม่ถูกแชร์ในห้อง

### Discord

ตั้งค่า › Discord › เปิด "แสดงเรื่องที่กำลังดูใน Discord" แล้วใส่ Application ID:
ไปที่ [discord.com/developers](https://discord.com/developers/applications) › **New Application** › ตั้งชื่อ `Waku` › คัดลอก **Application ID** มาวาง (ต้องเปิดแอป Discord บนเครื่องเดียวกัน)

## อัปเดต

ตั้งค่า › **อัปเดต**
- แอปตรวจหาเวอร์ชันใหม่ตอนเปิด ถ้ามีจะแจ้งเตือน → กด "ดาวน์โหลดและติดตั้ง" → "เปิดใหม่ตอนนี้"
  (แอปตรวจ checksum SHA-256 ก่อนติดตั้งทุกครั้ง)
- **กฎดึงข้อมูลของแต่ละเว็บ** อัปเดตให้เองเมื่อมีรุ่นใหม่ ถ้าคุณแก้ไฟล์ `sources.toml` เองไว้ แอปจะถามก่อนและสำรองไฟล์เดิมให้

## แก้ไขแหล่งเว็บเอง

`%APPDATA%\waku\sources.toml` (ตั้งค่า › "เปิด sources.toml") — เว็บย้ายโดเมนบ่อย ส่วนใหญ่แก้แค่ `base` แล้วกด "โหลดแหล่งใหม่"
รายละเอียดแต่ละช่องอยู่ในคอมเมนต์ของไฟล์

## Build จาก source

ต้องมี [Rust](https://rustup.rs) (stable) และ clone **สอง repo ไว้ข้างกัน** เพราะตัวเล่นอยู่อีก repo:

```powershell
git clone https://github.com/sapph1rer/waku-app
git clone https://github.com/sapph1rer/rmp
cd waku-app
cargo build --release
```

ได้ไฟล์ที่ `target\release\` (`waku-app.exe`, `waku-browser.exe`) แล้ววาง `libmpv-2.dll` ไว้ข้างกัน
(ดู `rmp\third_party\libmpv\README.md` หรือใช้ปุ่มดาวน์โหลด libmpv ในหน้าตั้งค่า)

```
waku-app/
├─ crates/waku-core/      ดึงข้อมูลจากเว็บ, metadata, ตัวหาลิงก์วิดีโอ  (sources.default.toml = กฎของแต่ละเว็บ)
├─ crates/waku-app/       หน้าตาแอป (egui), ดาวน์โหลด, watch party, อัปเดต
├─ crates/waku-browser/   ตัวช่วย WebView2 (Cloudflare / หน้า player)
├─ scripts/               make-release.ps1
└─ docs/DEVELOPMENT.md    บันทึกการพัฒนาและการทำงานภายใน
```

### ออกเวอร์ชันใหม่ (สำหรับผู้ดูแล)

1. แก้ `version` ใน `crates/waku-app/Cargo.toml`
2. `powershell -ExecutionPolicy Bypass -File scripts\make-release.ps1 -Notes "มีอะไรใหม่"`
   — build → `dist\waku-windows-x64.zip` + `.sha256` → สร้าง Release บน GitHub (ต้องติดตั้ง [GitHub CLI](https://cli.github.com) และ `gh auth login` ครั้งแรก)

### อัปเดตกฎดึงข้อมูล (สำหรับผู้ดูแล)

แก้ `crates/waku-core/sources.default.toml` แล้ว **เพิ่มเลข `revision`** จากนั้น push ขึ้น branch `main` — ทุกเครื่องจะได้กฎใหม่ในการเปิดแอปครั้งถัดไป

## ข้อจำกัด

- บางเว็บใช้ Cloudflare — การเปิดครั้งแรกหลังติดตั้งอาจช้า 5–10 วินาที ครั้งต่อไปจะเร็ว
- เว็บต้นทางเปลี่ยนหน้าตาได้ทุกเมื่อ ถ้าเว็บไหนใช้ไม่ได้ ดูที่หน้า "สถานะแหล่ง" และรอกฎอัปเดต
- ชื่อตอน / เรื่องย่อของเรื่องที่ใหม่มากอาจยังไม่มีในฐานข้อมูล
- สระ / วรรณยุกต์ไทยบางคำอาจซ้อนไม่สวย (ข้อจำกัดของ egui)
